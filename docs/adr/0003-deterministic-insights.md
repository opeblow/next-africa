# ADR 0003 — Deterministic insights and nudges

- Status: Accepted
- Date: 2026-09-18

## Context

Insights and nudges could be generated by an LLM, but that adds latency, cost,
and non-determinism to a screen that should feel instant and trustworthy.

## Decision

Compute insights (`/api/insights`) and nudges (`/api/nudges`) with plain SQL and
small TypeScript-free JavaScript rules. Persisted conflict nudges are written by
the capture pipeline; due/waiting nudges are computed on read and deduplicated
against a `(user_id, source_key)` table so users can dismiss them.

## Consequences

- Sub-millisecond responses, zero token cost, fully testable.
- Copy is templated rather than free-form; acceptable for this product.
- An LLM summary can be layered on later without changing the contracts.
