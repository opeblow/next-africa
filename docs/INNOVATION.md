# Product differentiators and boundaries

1. **Context across messages.** Capture includes the user's 100 most recently updated
unfinished commitments. The model can return an existing ID, which the server checks
for ownership before linking. Same-message title linking remains supported. This is
bounded context, not unlimited memory or a claim that other products lack this feature.
2. **Conflicts and follow-through.** Capture flags nearby deadlines/meetings. Users can
review deadlines, prepare an editable follow-up draft, and explicitly record completion.
Draft generation does not send messages or change task status.
3. **Configurable reminders.** Quiet, balanced and active preferences change due windows
and waiting thresholds. A 24-hour snooze and opt-in daily push summaries support follow-up.
Preferences are user-controlled, not inferred behavioral learning.

## Boundaries

No direct WhatsApp integration, calendar sync, autonomous execution or automated sending.
PDF support is for text PDFs up to 20 pages; scanned pages can be attached as images.
AI quality and browser push delivery must be checked with live credentials and a supported
browser before recording a demo. Existing GIFs may show an older interface.
