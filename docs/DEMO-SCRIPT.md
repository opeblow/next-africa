# Demonstrate a real follow-through loop

Use a test account and describe example client messages as sample data. Use a real AI
key for the final recording; do not replace live results with mocked responses.

1. Paste a client request with an explicit deadline. Review the extracted items and dates.
2. Add a later message about the same project. Show the project link and a nearby deadline warning.
3. Open the workspace, correct a deadline, and prepare an editable follow-up draft.
4. Copy the draft for review. Explain that NEXT does not send it automatically.
5. Mark only the work actually finished as done. Show open/waiting work remains unfinished.
6. Show how reminder preferences and a 24-hour snooze change the reminder list.
7. Optional: enable push in a supported browser and show a real notification.

Do not claim an autonomous agent completed the user's task. Progress is saved user
confirmation. Do not claim PDF OCR, WhatsApp integration, or self-tuning preferences.
